# Online-shopping-data-analysis
An end-to-end data analytics project using the Online Retail dataset to explore sales performance, understand customer purchasing behavior, and present business insights through interactive dashboards.
Project Overview
This project covers: - Data cleaning and preparation - Revenue
calculation and sales analysis - Product and country performance
analysis - Customer-level RFM analysis - K-Means customer segmentation -
Interactive reporting in Power BI - An optional Streamlit dashboard

Tools & Technologies
- Python, Pandas and NumPy
- Scikit-learn for feature scaling and K-Means clustering
- Google Colab for cloud-based Python execution
- Power BI Desktop for interactive reporting
- Streamlit for an optional web dashboard
- Pyngrok for optional temporary public access to a Colab-hosted
  Streamlit app

  Data Preparation
Typical preparation steps include: 1. Identifying cancelled invoices
(often marked with an invoice number beginning with C). 2. Handling
missing customer identifiers for customer-level analysis. 3. Checking
invalid or non-positive quantities and unit prices. 4. Converting
InvoiceDate to a datetime data type. 5. Calculating revenue

Analysis
Sales Analysis
The project can analyze: - Total revenue - Total orders - Total
customers - Total products - Total quantity sold - Monthly revenue
trends - Top-performing products - Revenue by country

RFM Customer Analysis
RFM describes customer purchasing behaviour:
- Recency: Days since the customer's most recent purchase,
  relative to the analysis reference date.
- Frequency: Number of distinct invoices/orders made by the
  customer.
- Monetary: Total revenue generated by the customer.
The RFM values can be transformed and scaled before K-Means clustering.
Select the number of clusters based on evaluation results and whether
the resulting groups are meaningful.

Power BI Dashboard
Suggested report visuals: - KPI cards: Total Revenue, Total Orders,
Total Customers, Total Products and Total Quantity - Monthly Revenue
Trend line chart - Top 10 Products bar chart - Country-wise Revenue
donut chart - Country and Invoice Date slicers

How to Run
Python / Google Colab
1. Open the analysis notebook in Google Colab.
2. Upload or connect to the dataset.
3. Run the notebook cells in order.
4. Review the cleaned data, sales analysis and customer segmentation
   outputs.
Power BI
1. Open the .pbix file in Power BI Desktop.
2. If prompted, update the dataset path or reconnect the data source.
3. Refresh the data.
4. Explore the report using its slicers and visuals.
